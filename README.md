# Focal AI — Cinematic Landing Page

An Awwwards-inspired, high-performance cinematic landing page for **Focal** — an intelligent desk companion designed to protect deep focus hours and quiet notifications.

## ✨ Features

- **Full-Page Cinematic Video Background:** Seamless looping celestial video rendered across all sections with responsive dark ambient vignette overlays.
- **Dynamic Scroll-Spy Navigation:** Floating pill navbar tracking viewport progress with warm neon amber active states.
- **Interactive Focus Modes:** Real-time filter toggles across *Deep Work*, *Meetings*, *Wind Down*, and *Recharge* with dynamic interruption statistics.
- **Reactive Workflow Cards:** Interactive sound wave rhythm sync, interactive notification toggle states (*Hold*, *Block*, *Allow*), and live flow-state timer increments.
- **Glassmorphism & Depth:** Backdrop-blurred glass cards with custom spotlight glow reflections and micro-animations.

---

## 🛠️ Tech Stack

- **Framework:** React 18 (Vite 5)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Custom CSS Variables & Gradients
- **Icons:** Lucide React
- **Typography:** Playfair Display (Serif/Italic) & Inter (Sans)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ayush-3945/focal-ai-landing-page.git
cd focal-ai-landing-page
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Production Build

```bash
npm run build
npm run preview
```
